## Task 1 — Core: `Kredi` domain + `KrediTuretici` (saf, ağır test)

**Dosyalar:** `Kasa.Core/Kredi.cs` (yeni), `Kasa.Core/KrediTuretici.cs` (yeni),
`Kasa.Core.Tests/KrediTureticiTests.cs` (yeni).

`Kredi` record:
```csharp
public record Kredi(
    string Ad,
    decimal CekilenTutar,
    DateOnly CekimTarihi,
    int TaksitSayisi,
    decimal AylikOdeme,
    int OdemeGunu,
    string Kanal);   // gerçek kanal adı VEYA Kanallar.Ortak
```

`KrediTuretici` (saf, static):
- `Gelen? CekimGeleni(Kredi k, IReadOnlyList<Donem> donemler)`
  - `CekimTarihi`'ni içeren dönemi bul; yoksa `null`.
  - `new Gelen(donem.Start, "__KREDI__", k.CekilenTutar)`.
  - `public const string KrediKanal = "__KREDI__";` sabiti burada.
- `IReadOnlyList<Islem> TaksitGiderleri(Kredi k)`
  - `TaksitSayisi` adet `Islem(taksitTarih, k.Ad, k.AylikOdeme, k.Kanal, GiderTipi.Cari)`.
  - İlk taksit: `CekimTarihi`'nden SONRAKİ ilk `OdemeGunu` tarihi.
  - Sonraki taksitler aylık artışla; kısa aylarda gün ay sonuna sabitlenir (clamp).
  - Tarih üretimi için gün-clamp mantığı: mevcut `KartDonem.GunClamp` özel; buraya küçük
    bir yerel clamp yaz veya `KartDonem`'e paralel bir helper ekle (Core içi). **Yeni public
    API icat etme** — yerel private clamp yeterli.

**Testler (KrediTureticiTests):**
- `Cekim_dogru_doneme_yazilir` — CekimTarihi'ni içeren dönemin Start'ı, tutar, kanal `__KREDI__`.
- `Cekim_donem_disindaysa_null` — takvim dışıysa `null`.
- `Taksit_sayisi_kadar_gider_uretir` — count == TaksitSayisi.
- `Ilk_taksit_cekimden_sonraki_odeme_gunu` — çekim 03.08 / gün 15 → 15.08; çekim 20.08 /
  gün 15 → 15.09.
- `Kisa_ay_gun_ay_sonuna_sabitlenir` — gün=31, Şubat taksiti → 28/29.
- `Yil_sarmasi` — Aralık'tan Ocak'a geçen taksitler doğru yıl.
- `Taksit_kanal_ve_tutar_dogru` — her Islem Kanal==k.Kanal, TutarTl==AylikOdeme, Tip==Cari.
- `Ortak_kanal_korunur` — Kanal==Kanallar.Ortak ise Islem.Kanal==Ortak.

**Doğrula:** `dotnet test Kasa.Core.Tests`. Commit: `feat(core): kredi türetici (çekim geliri + taksit giderleri)`.

## Task 4 — Api: `HesapServisi.Yukle` türetilmiş kayıtları motora besler (KRİTİK)

**Dosyalar:** `Kasa.Api/Servisler/HesapServisi.cs`, `Kasa.Api.Tests/KrediMuhasebeTests.cs` (yeni).

`Yukle()` içinde:
1. `var krediler = _db.Krediler.ToList().Select(e => e.ToCore()).ToList();`
2. Dönemler üretildikten SONRA:
   - `gelenler` listesine her kredinin `KrediTuretici.CekimGeleni(k, donemler)` (null değilse) ekle.
   - `islemler` listesine her kredinin `KrediTuretici.TaksitGiderleri(k)` düzleştirilmiş halini ekle.
3. Bu birleşik listeleri `Yuk`'a koy. **DB tablolarına yazma yok** — yalnız bellek.

Sıralama dikkat: mevcut `enGecIslem`/`bitis` hesabı DB islemlerine bakıyor; türetilmiş
taksitleri de kapsaması için `bitis` hesabına türetilmiş taksit tarihlerini de kat (aksi
halde son taksitler dönem takvimi dışında kalıp güncel raporda görünmez). En temizi:
türetilmiş islemleri ekledikten sonra `enGecIslem`/`bitis`/`donemler`'i bu birleşik listeden
hesapla. **Ama** `CekimGeleni` dönem gerektiriyor → sıra: önce takvimi DB+taksit tarihlerine
göre üret, sonra çekim gelenini o takvimle türet. (İki-geçiş: 1) taksit giderlerini üret →
bitiş tarihini belirle → dönemleri üret; 2) çekim gelenlerini bu dönemlerle üret.)

**Testler (KrediMuhasebeTests) — uçtan, gerçek servisle:**
- `Cekim_genel_kasaya_girer_kanala_girmez` — bir kredi ekle; `/rapor/panel` guncelKasa
  CekilenTutar kadar artar; hiçbir kanal bakiyesi çekimden etkilenmez.
- `Taksit_secili_kanaldan_duser` — kanal=X kredi; taksit dönemi geçmiş; X kanalının haftalık
  sonucu AylikOdeme kadar azalır, genel kasa da azalır.
- `Ortak_taksit_aylik_raporda_bolunur` — kanal=Ortak; `/rapor/aylik` her aktif kanaldan eşit
  pay düşülür (mevcut Ortak dağıtımı).
- `Kredi_silinince_muhasebe_etkisi_kalkar` — DELETE sonrası guncelKasa eski haline döner.

**Doğrula:** `dotnet test Kasa.Api.Tests`. Commit: `feat(api): krediyi hesap motoruna türetilmiş kayıtla bağla`.

## Deploy (AYRI adım — kullanıcı onayı gerekir)

1. Prod DB'ye elle raw SQL (YIKICI OLMADAN):
   ```sql
   CREATE TABLE "Krediler" (
     "Id" INTEGER NOT NULL CONSTRAINT "PK_Krediler" PRIMARY KEY AUTOINCREMENT,
     "Ad" TEXT NOT NULL, "CekilenTutar" TEXT NOT NULL, "CekimTarihi" TEXT NOT NULL,
     "TaksitSayisi" INTEGER NOT NULL, "AylikOdeme" TEXT NOT NULL,
     "OdemeGunu" INTEGER NOT NULL, "Kanal" TEXT NOT NULL);
   ```
   (EF `EnsureCreated()` üreteceği şemayla birebir doğrula — build sonrası
   `dotnet ef dbcontext script` veya mevcut tabloların şablonuyla eşleştir.)
2. Kod sync (tar-over-ssh: Kasa.Core + Kasa.Api + Dockerfile) → `/opt/kasa`.
3. `cd deploy && docker compose -f docker-compose.nginx.yml up -d --build kasa`.
4. Uçtan doğrula: editör login → POST /api/krediler → /rapor/panel guncelKasa arttı → test
   kredisini sil.
5. Windows istemci: yeni sayfayı manuel doğrula (birim-test edilemez katman).
